384 做完之后，我们把"怎么把一段历史做成一个时代剧本"这件事本身整理成了一套 [方法论](方法论/README.md)——不是 384 的内容，是流程：怎么筛人物、怎么配数值、怎么借派系壳、怎么画旗、怎么写脚本、怎么在真游戏里测。以后做别的时代会直接照这套走（方法论开头有一份“新时代照着做的顺序”，十三步）。
