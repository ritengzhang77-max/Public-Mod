# 13 · 人物性格、人物关系与藩镇猜忌

## 384 里发生了什么

人物、立绘、五维都齐了之后，玩家试玩又指出三处“空着”的地方：

1. 选派系界面「人物」一栏只有职业（“指挥”），下面的特性是空的；原版的王爷在那里有三个性格。游戏里名人的性格也是生成时随机来的，常常和史书对不上。
2. 人物面板的「人物关系」完全是空的：只有父子（脚本 `make_child_of`）和四对夫妻。
3. 东晋朝廷和北府、桓氏两大藩镇之间，历史上是一轮一轮的猜忌和摊牌（王恭两度起兵、刘牢之倒戈、桓玄篡晋、刘裕讨桓），游戏里却只是三个互不相干的附庸关系。

三件事的共同点：历史里人与人、家与家之间的“关系”，要变成游戏里看得见、会起作用的东西。

## 一、性格特性

**游戏里是什么**：性格是一种 CEO，键是 `3k_main_ceo_trait_personality_<名字>`（`brave` 英勇无畏、`cunning` 奇谋百出、`disloyal` 不臣之心……）。定义在编译好的 CEO 数据里，**不能新增，只能挑**。

**两个地方要改**：

| 位置 | 做法 |
|---|---|
| 选派系界面「人物」一栏 | `frontend_character_ceos`（ceo、frontend_character、`reason = trait`、`threshold_points = 1`）。原版王爷每人三行 |
| 游戏里的人 | 脚本：`ceo_management():all_ceos_for_category("3k_main_ceo_category_traits_personality")` 读出随机来的，`remove_ceos(键)` 摘掉，`add_ceo(键)` 加上，再读一遍核对。原版议事厅换性格也是这个顺序 |

**做法**：

- 一份数据（384 是 `data/personality_384.yaml`）给名人各写三个性格，按史事挑。比如：
  - 苻坚：雄心勃勃、与人为善、言听计从（淝水后被自己宽待的降将所叛）；
  - 姚苌：奇谋百出、不臣之心、笃信鬼神（晚年梦见苻坚率鬼兵入营）。
- **只用原版界面表里出现过的键**，保证每个键都存在。
- 同一份数据既写界面表，也给开局脚本用：选派系界面上看到的，就是游戏里真有的。
- 没写的人保持随机性格，不必人人都写；君主和名人写全就够了。
- 日后才登场的人，登场那天一起换。

**给已经在玩的存档补上**：读档时补换一次，并记在存档里；以后游戏里自己长出来的性格不再动，不会每次读档都把玩家的变化冲掉。

## 二、人物关系

**游戏里是什么**：

- 一对人只有一个分数。到阈值就成关系：好友 ≥ +100、义亲 ≥ +300、敌手 ≤ −100、死敌 ≤ −300。
- 成了之后要跌过另一条线才散：好友跌破 +20，义亲跌破 −100（等于终身）。
- 分数每回合往 0 回落几点。分数夹在 +300 / −250 之间。
- 每人最多 7 个好友、义亲、敌手、死敌，外加 11 个相识。

**脚本只有一种写法**：`modify_character(A):apply_relationship_trigger_set(query B, 触发组)`。每个触发组加减一定分数，留一句“记忆”（鼠标悬停时看到的那句话）。原版孙策—周瑜就是「总角之交 +100」加「泛用极大 +200」凑满 300 成义亲。

**我们用的五种**，都是只作用于这两个人、不牵连第三人的触发组：

| 种类 | 触发组 | 分数 |
|---|---|---|
| 家人 | `startpos_family_member` | +50 |
| 好友 | `event_positive_generic_extreme` | +200 |
| 义亲 | 上一个，再加两次 `..._large` | +300 |
| 敌手 | `event_negative_generic_extreme` | −200 |
| 死敌 | 上一个施加两次 | −400，下限是 −250，能不能成死敌还没验证 |

**规则**：

- 两个人都活着才施加。开局都在的开局施加；有一个日后登场的，登场那天施加；对方已死就算了。
- 每对只施加一次：重复施加分数会叠上去，好友可能升成义亲。
- 游戏的家谱只认活着的父亲。父亲早死的兄弟、舅甥、姻亲，用“家人”补上。
- 生成器检查每人的好友、敌手类关系不超过 6 个：游戏自己还会给新生成的人随机结几个。
- 每对写一句史料出处（384 是 `data/relationships_384.yaml` 的 `note`），方便以后核对。

**实测**：关系栏显示「义亲」「敌手」。悬停显示原版的记忆行，比如“我们是家人……”“一路走来我们增进了彼此的了解”。想要自己的记忆文字，就得另建触发组和记忆行，没做。

## 三、把势力之间的历史关系做成机制：藩镇猜忌

**需求**：北府、桓氏是晋的附庸，但历史上迟早要和朝廷摊牌。玩家要的是“互相猜忌提防”，并且“高于某个值就每回合扣一些”。

**设计**（384 是 `data/suspicion_384.yaml` 加一个脚本文件）：

1. **记数**：朝廷对每个藩镇记一个猜忌值（0~100，存在存档里）。朝廷每回合开始结算一次：
   - 基本 +1；
   - 藩镇地盘接近朝廷再加；
   - 藩镇打赢一仗 +1（功高震主）；
   - 某人当家之后涨幅翻倍（桓玄）。

   AI 也照样跑。
2. **到 50**：双方各挂一个“互相提防”的派系效果包，回落到 50 以下就摘。藩镇：补员、征募变差；朝廷：纳贡变少、民心下降。
3. **到 100 摊牌**，分三种情况：
   - 两边都是 AI：藩镇起兵。
   - 玩家是藩镇：弹窗选「起兵」或「交钱请罪」。
   - 玩家是朝廷：弹窗选「削藩」或「花钱安抚」；拖着不理，几回合后藩镇自己起兵。
4. **起兵的做法**：原版有一个外交处置 `data_defined_situation_vassal_declares_independence`，由附庸提出。先让藩镇宣布独立，再用 `..._war_proposer_to_recipient` 对朝廷宣战。
5. **终局目标**：桓氏独立后打下建康，得一个永久的效果包「问鼎江左」。
6. **玩家看得见**：「势」窗口里多一行当前猜忌值；选派系界面「特有特征」里三家各一项，写清规则。

**通用**：凡是“名义上的上下级、实际上的对手”——藩镇、宗王、权臣、部落联盟——都能照这个套路做：一个数，几条涨法，两道线（先扣、后摊牌），AI 和玩家各一条出路。

**待实测**：由脚本发起的“宣布独立”是否真的解除附庸。脚本已经写了日志：看 `still a vassal=false`。

## 四、叛军按地分家

**384 里的问题**：全图的叛军原来是同一个派系，天南地北的叛军一起宣战；玩家看到一家叛军（“杜秀”）遍布全图。

**游戏里的规矩**：

- 叛军派系可以按城划分：南蛮 DLC 的先例是 `campaign_group_member_criteria_regions` 加 `campaign_group_rebel_shadow_factions`。
- 但划出来的每一路，都得是**开局存档里本来就有的叛军派系**。
- 八王之乱的开局存档里只有两个：`ep_faction_rebels` 和 `ep_factions_shadow_rebels`。190 和南蛮的叛军派系都不在里面。

**做法**：按秦岭—淮河分南北，南方 115 座城归一家（改名「江南盗」），北方归另一家（「流民坞帅」）。改名只影响这个剧本。

**要分更多家**，得往开局存档里新建派系，还没做。

## 下个时代照着做

1. 君主和名人的性格写进一份数据，同时喂界面表和开局脚本；只用原版界面用过的键。
2. 按史事列关系对：谁是义亲、好友、敌手、死敌，谁是父亡的兄弟、舅甥；写出处；每人不超过 6 个。
3. 找出这个时代最有特点的一对（或几对）势力关系，做成“一个数、两道线、两条出路”的机制，并在玩家能看到的地方写清楚。
4. 叛军分区先查开局存档里有几个叛军派系，再定怎么分。
