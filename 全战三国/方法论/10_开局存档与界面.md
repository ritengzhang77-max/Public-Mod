# 10 · 开局存档与界面：年份、选派系头像、胜利条件、官制

## 384 里发生了什么

384 是借「八王之乱」（291 年）这个剧本做的：开局第一回合由脚本把人、地盘、战争全部换成 384 年的样子。能用脚本改的都改了，但有几样一直"改不了"：

- 界面上的年份永远是 291；
- 选派系界面右上角的大名字是 291 年那位王爷（选前秦，写着"司马建"）；
- 列表里的圆头像是游戏自带的通用脸，不是我们给 384 人物画的立绘；
- 派系概览里「终极胜利」那一栏写着"消灭八王"，列的是八个早已不在场的司马王爷；
- 晋是 384 年唯一的正统皇帝，府署却和别家一样只有"丞相 + 五个尚书位"，没有三公九卿。

这些东西都不在脚本能碰到的地方，而是写在**开局存档**（start position）和**界面版式文件**里。后来我们写了开局存档的读写工具，自己生成一份开局存档，这几样就都能改了。下面是这一轮摸清楚的机制，换任何一个时代都用得上。

## 一、开局存档是什么、怎么改

- 位置：`campaigns/<剧本>/startpos_romance.esf` 和 `startpos_historical.esf`（演义 / 正史各一份），在游戏自带的 data.pack 里。
- 格式：CA 的 ESF 二进制树。外层是一棵小树；里面有一个 LZMA 压缩块，解开是另一棵完整的树（整个世界：派系、人物、城池、AI 状态……）。两层都有一份 `CAMPAIGN_PREOPEN_MAP_INFO`（选派系界面用的摘要），改的时候**两份都要改**。
- 工具要求：读进来再原样写出去必须**逐字节一致**。我们用原版、黑熊、NewFactionsAddon 三家的开局存档验证过。做到这一步之后，改任何字段都只动那一个值。
- 原则：**以游戏本体的那份为底**，不以别的 mod 的为底，改什么写在一个配置文件里（年份、谁能选、名字、旗帜、胜利条件、政体），每次构建重新生成。这样既不背别家的依赖，也能随时看清自己改了什么。

### 改过、并在游戏里验证过的字段

| 想改的 | 在存档里的位置 | 注意 |
|---|---|---|
| 年份 | 外层 2 处 + 内层 5 处（存档头、预览信息、日历） | 其余所有日期（出生年、任职记录）平移同样的年数，岁数才不变 |
| 谁能选 | `FACTION_INFOS` 每条的第 3 个值、`PLAYERS_ARRAY` 每条的第 3 个值 | 布尔值的类型码是 0x12（真）/ 0x13（假） |
| 选派系界面的名字、旗帜 | `FACTION_INFOS`：旗帜路径 + `CHARACTER_NAME`（四个名字键） | |
| 右上角的大名字 | 开局世界里持 `faction_leader` 官位的那个人物的名字 | 找人：派系的官位表里 faction_leader 的 id，对上人物 `ACTIVE_CHARACTER` 里的官位 id |
| 胜利条件 | `VICTORY_MISSION_OPTIONS`：每个派系一条，短期 / 终极两个任务 | 目标有 `ATTAIN_FACTION_PROGRESSION_LEVEL`（等级）、`DESTROY_FACTION`（派系名单 + 数量） |
| 政体（王国 / 帝国） | 派系的 `GOVERNMENT`：类型（1 王国 / 0 帝国）+ 现行官制的官位 + 另一套官制的官位 | 见第四节 |
| 选派系地图上图钉的位置 | `FACTION_INFOS` 每条里的一对 0～1 坐标 = 君主坐标 ÷ (595.10, 541.79) | 占位值 (0.0011, 0.0021) 时界面才用 `override_force_location`；见[第 11 节](11_选派系界面_开场动画_派系势.md) |

## 二、自己的开局存档怎么才能生效：包的类型和顺序

同一路径的文件在多个包里都有时，只有一个生效。实测结论：

1. **电影类型（movie）的包压过所有普通 mod 包**。NewFactionsAddon 把它的八王开局存档放在电影包里，我们放在普通 mod 包里的那份就不生效：年份还是 291，原版的淮南王还在。
2. 电影包之间按文件名排序，排在前面的赢（`!!` 开头最靠前）。
3. 电影包**不用在启动器里勾选就会加载**，只要文件在 data 目录里就生效。
4. 数据库表片段、文字文件（.loc）也是按名字排、排前面的赢；我们的等级名曾经被另一个 mod 的 `text/!03_faction_ranks.loc` 盖掉，把自己的改名为 `text/!!…loc` 才赢回来。

所以开局存档在主包里放一份（没有冲突时就够了），另外单独打一个 `!!` 开头的电影小包（有别家开局存档时用它压过去）。代价是第 3 点：装着这个小包，就算不勾主包，八王之乱开局也会变成 384 年的世界，只是没有脚本。

## 三、选派系界面：头像、名字从哪里来

- **列表里的圆头像、地图上的图钉**：来自"界面人物"（`frontend_characters`）所用的那个人物模板的 `art_set_override`（美术套装）。改开局世界里那个人物的美术套装不起作用。图钉上的**画**是这里定的，图钉的**位置**不是：位置写在开局存档的 `FACTION_INFOS` 里，见[第 11 节](11_选派系界面_开场动画_派系势.md)。
- 不能把界面人物整个换成我们自己的新模板：试过两次，一次头像变成没脸的盔甲，一次点「新战役」就崩。**可行的做法**是界面人物和模板都不动，只覆盖那个旧模板的一行数据，把 `art_set_override` 换成我们给这个君主做的美术套装。12 家全部换成我们的画，没有出问题。
- **右上角的大名字**：取自开局世界里的君主本人（见第一节表格），只能在开局存档里改。
- 列表里头像下面那行字：界面人物的模板有姓名就显示姓名，没有才显示我们写的副标题。
- 列表里的**小圆头像**要“脸”那一层：原版版式里这几个头像只有一个图位（盔甲），脸的设置被关着。要自己带一份版式，给这几个头像补一个脸的图位，并在每个状态里画出来（见第 09 节）。
- 界面人物的“特色”（`optional_specialisation`）最好填一个效果包：可以是只用来显示的空包，写上派系特色的名字和说明。有的版式按它决定头像下显示哪行字，空着时名字会不见。
- 界面人物的职业键要用对：水（军师）是 `3k_main_hero_strategist_water`，不是 `3k_main_hero_water`。写错时游戏会悄悄把这一家从列表里去掉。

## 四、界面上写死的东西，怎么绕开

有些界面看着是"数据驱动"，其实版式文件里写死了。办法是在自己的包里放一份同名的版式文件，只改那一处。

- **派系概览的「终极胜利」头像栏**：版式文件 `faction_progression_panel_8p_start_pos.twui.xml` 里，这一栏的列表来源写的是 `EightPrincesFactionList`，永远是那八个王，和胜利任务无关。换成一个过滤表达式：

  ```
  CampaignRoot.FactionList.Filter((x) => x != PlayersFaction && (x.FactionRecordContext.Key == "…" || …))
  ```

  这样就只列我们指定的几家强权，排除玩家自己；活着的显示君主立绘，灭亡的变灰。
  - 表达式要用游戏自己的版式文件里出现过的写法，拼的时候照抄已有的例子最稳。
  - 旁边"夺天子称帝 / 当摄政"两个框加 `visible="false"` 就藏起来了。
- **府署（官制）界面**：版式文件按名字查找，越具体越优先：`court_screen_<剧本>_<派系>[_imperial_court]` → … → `court_screen_<剧本>` → `court_screen_imperial_court`。
  - 八王之乱自带 `court_screen_8p_start_pos`，里面只有王国官位，它排在通用的"皇宫"版式前面。
  - 所以给改成帝国的那一家单独放一份皇宫版式，文件名写到派系；文件里根节点的 id 要跟着文件名改。
  - 实测起作用的是不带 `_imperial_court` 后缀的那个名字（只放带后缀的，又退回了王国版式）。也就是说版式跟着派系走、不跟着政体走：在政体还没改的旧存档里，这一家的府署会变成空的皇宫版式。
- 改版式文件之前，先确认**没有别的 mod 也改了同一个文件**（扫一遍所有启用的包），再确认**这个文件只有这个剧本用**，免得连带改了别的剧本。

## 五、政体：让正统王朝一开局就有三公九卿

- 每个派系在开局存档里**两套官制都存着**：
  - 现行的一套：王国是 9 个官位（君主、储君、太守、丞相、五个尚书）；
  - 备用的一套：帝国是 17 个（君主、储君、太守 + 三公九卿 14 个）。
- 190 剧本里称帝时，引擎会把两套对调；八王之乱里没有东西能触发这个对调。
- 182 剧本的开局存档里，何皇后的汉廷就是"开局即帝国"：类型 0，现行的是 17 个帝国官位。照着它改就行：
  1. 类型 1 改成 0，两块官位对调；
  2. 持官位的人（君主、储君）改指到另一块里同名的官位；
  3. AI 那份官位表两套都有，不用动。
- 脚本封官时用帝国官位的键（`3k_dlc04_court_offices_…`）就能封上。
- **界面上要显示出来，还差两样**：
  - 这些官位在 `ministerial_positions_culture_details` 里的显示行。原版只给少数几家写过专属行，没有通用的，照抄一家的再改派系、剧本、开放条件。
  - 上一节说的皇宫版式文件。
- 换政体之后，这一家的派系等级跳了一级（声望没变）。
- 注意：这只是开局就定好的政体。别的派系在游戏中途称帝时，八王之乱里仍然换不了官制。

## 六、下次做新时代时的检查单

1. 先列出"脚本改不了、只能靠开局存档改"的东西：年份、右上角大名字、谁能选、胜利条件、开局政体。
2. 生成自己的开局存档：以游戏本体的为底，改动写进配置文件；每次构建重新生成，并检查读回。
3. 装好后在游戏里确认生效：选年份界面的年份、第 1 回合的日历。没生效，就是别的包里的开局存档压过了它（第二节）。
4. 选派系界面的头像：覆盖界面人物背后那个模板的美术套装，不要新建界面人物。图钉位置写进 `FACTION_INFOS`（第 11 节）。
5. 胜利条件写进开局存档；派系概览上的胜利栏另外改版式文件，两边的名单要对上。
6. 界面版式按"剧本 / 派系"专属文件覆盖，先扫一遍别的 mod 有没有同名文件。
7. 每改一样都进游戏开一局、过一回合，截图对照。
