# 11 · 选派系界面、开场动画、派系"势"

这一节是 384 最后几轮（0.9.10～0.9.15）做的三件事：选派系界面分组和图钉、自己做的开场动画、每家一套攒点发动的"势"。开局存档和界面版式的基础机制见 [10](10_开局存档与界面.md)。

## 一、选派系界面：两组势力

### 384 里发生了什么

- 最早借壳的派系散在「其他诸侯」一长串里，和八王之乱的旧王爷混在一起。玩家问：能不能把真能用的放在最前面单独一组？后来又说："入场选择 384 分两类，主角和其他小地方势力。"
- 现在是两组：「淝水之后 · 主要势力」12 家、「淝水之后 · 地方势力」8 家。只有日后才入场的吕光（385）和孙恩（399）不能选。八王之乱原来的王爷一个都不出现（开局存档里设成不可选，见 [10](10_开局存档与界面.md)）；游戏自带的「当前年份不可扮演」一组是原版行为，去不掉，也不影响。
- **为什么地方势力以前选不了**：选派系界面只认开局存档里"活着"（有地盘、有君主）的派系。这 8 家借的壳全是八王之乱里开局休眠的豪强、王爷（见 [05](05_派系壳与借壳机制.md)），所以只能当 AI。办法是把它们都换到 291 年开局就活着的王爷身上，和 12 家主要势力的做法一样：

  | 势力 | 原来的壳（休眠） | 换到（开局活着） |
  |---|---|---|
  | 秦·凉州 | 武威豪强 | 陇西王 |
  | 秦·洛阳 | 洛阳豪强 | 宜阳王（宜阳就在洛阳西边） |
  | 秦·幽州 | 范阳王 | 长乐王 |
  | 秦·平州 | 辽西王 | 平原王 |
  | 丁零 | 东郡豪强 | 东安王（291 年正好据东郡的东平一城） |
  | 铁弗 | 朔方豪强 | 顺阳王 |
  | 晋·岭南 | 南海王 | 苍梧王（291 年就在岭南） |
  | 晋·宁州爨氏 | 建宁豪强 | 江阳王 |

  地图颜色照抄原来的壳（`colours_from`），字旗不变（字旗的底色就是按原来的颜色配的）。那几家豪强不再是壳，所以东郡、洛阳、朔方、武威、建宁这几个郡的"叛军接手派系"也改回了原版（不会再撞车，见 [05](05_派系壳与借壳机制.md)）。
- 实测（只开 384）：两组都在，8 家头像和文字齐；选梁熙开局，日志 `leader of ep_faction_prince_of_longxi is now 梁熙`，3 座城，结束一回合后「势」从 6 涨到 9。

### 机制

| 要什么 | 在哪里定 | 注意 |
|---|---|---|
| 分组和组的先后 | `faction_groups`（标题、顺序）+ `faction_to_faction_groups_junctions` | 关联表的键是"派系 + 剧本"，分组不在键里——同键的一行就能把派系挪到别的组；文件名以 `!` 开头排在别的 Mod 前面 |
| 组内的先后 | `frontend_factions.sort_order` | 实测改了没用，是游戏内部顺序，放弃 |
| 能不能被选到 | 界面四张小表 + 政党三张表（findings 第 60、72 条） | 可选的界面首领要属于这个派系的一个 playable 政党；键用派系键，和常见的解锁 Mod 同键，同时开时整行顶掉，不会一家两个头像 |
| 列表里有没有这一家 | 开局存档 `FACTION_INFOS` 的可选位（第 76 条）+ 派系开局要活着 | 休眠派系在列表里出不来 |
| 头像 | 界面人物背后那个模板的 `art_set_override` | 见 [10](10_开局存档与界面.md)；界面人物的职业键写错，这一家会悄悄从列表消失 |
| 头像下的字 | 模板有名字就显示名字，否则显示副标题；自带的版式对这些首领显示副标题（"姓名·外号"） | 第 49、74 条 |
| 右侧地图的着色 | `frontend_faction_map_relationships`（选中派系 + 另一家 + 剧本 → 宗主 / 附庸 / 敌对……） | 没有行的派系不着色；按自己的附庸表和开局战争生成 |
| 地图上各家的疆域 | 开局存档外层的疆域摘要 | 否则是 291 年的（选秦亮的是广陵） |
| 「推荐人物」一栏 | `frontend_faction_leaders.is_recommended` | 显示的是开局世界里现任君主的姓名头像；384 把它清空了 |

数据写在 `data/faction_shells.yaml` 的 `frontend_groups`（两组各列哪些派系）和 `data/frontend_384.yaml`（每家的姓名、副标题、人物背景、"侧重风格"一行）。

## 二、选派系地图上的图钉

### 384 里发生了什么

点「显示地图」时，有的图钉在 384 年的都城，有的还在 291 年那位王爷站的地方：苻坚在广陵、梁熙在陇西、爨璋在江阳。以前以为图钉位置来自 `frontend_faction_leaders.override_force_location_x/y`，改了之后只有一部分对。

### 机制（findings 第 78 条）

- 开局存档外层每个派系的预览信息 `FACTION_INFOS` 里有一个数组（类型码 76），装着两个 float32，范围 0～1。
- 这两个数 = **那一家君主在开局世界里的坐标**（人物 `ACTIVE_CHARACTER/LOCOMOTABLE` 的 coord2d）**÷ (595.10, 541.79)**。原版八王之乱 45 位君主全部精确吻合。
- 君主不在地图上的派系，这里是占位值 **(0.0011, 0.0021)**，这时界面才退回 `override_force_location_x/y`。所以只改 override 只对一部分派系有效。
- 休眠派系这个数组是空的（它们本来也没有图钉）。
- 外层、内层各有一份 `FACTION_INFOS`，两份都要改。

### 做法

`tools/make_startpos_384.py` 的 `set_faction_pins`：对每个可选的 384 势力，取它都城所在地区的中心（从原版数据里地区的外框算中心），除以 (595.10, 541.79)，写进这对坐标。休眠的日后入场势力跳过。实测：选苻坚，大图钉在长安，其余各家都在自己的都城。

## 三、开场动画：画的背景 + 立绘 + 诗

### 384 里发生了什么

- 八王之乱开局放一段 141 秒的八王动画，和 384 年毫无关系。玩家："入场动画不对了，能不能跳过或者甚至重做。"
- 第一版是羊皮纸底 + 我们的立绘 + 一段说明文字的无声幻灯片。玩家："每个人再写首诗什么的多帅啊"——于是每张配一首诗；背景交给出图方画（提示词见 [06](06_旗帜与美术资源生成.md)）。
- 最后一版是出图方给的 10 幕分镜（玩家批准），共 80 秒：淝水 → 长安·苻坚 → 邺城·慕容垂 → 关中·慕容冲、姚苌 → 荆楚·桓玄 → 代北·拓跋珪 → 朔方·刘勃勃 → 三吴·孙恩 → 京口·刘裕 → 天下。
- 玩家的几条意见，下次直接照做：
  - "我的诗就足够了，不用那句介绍语"——画面上**只有题目和诗**。诗的出处（借咏 / 史书原文 / 后来语 / 新拟）只留在数据里备查。
  - 背景太暗的换成更明亮的几张。
  - 两个人物时一左一右，题目和诗放中间（`layout: flank`）。
  - 不喜欢的诗就换，玩家自己拟的句子照用。

### 做法

数据 `data/intro_384.yaml`：

```yaml
slides:
  - seconds: 8
    background: bg_04_guanzhong        # art/intro/<名字>.png；没有图时用羊皮纸底
    portraits: [yao_chang, murong_chong]
    layout: flank
    title: 关中·慕容冲、姚苌
    poem: |
      凤皇凤皇止阿房，
      龙骧何事负秦王？
    source: 前句史载长安童谣；后句新拟    # 只留在数据里，show_sources: true 才上画面
loading:                                  # 开局加载时轮播的 4 张：图上不写字
  - {background: bg_01_feishui, portraits: [fu_jian], title: 淝水之败, text: …}
timeline_icon: {glyph: 淝, field: "#6b1f1f", ink: "#f1e6c8"}
```

流水线 `tools/make_intro_384.py`：

1. **每一幕画成一张 1920×1080 的 PNG**（PIL）：背景铺满 → 给文字区叠一块半透明的纸 → 立绘从下边缘站到接近顶部 → 楷体写题目和诗。
2. **ffmpeg 编成 VP8**：每张图循环 N 秒、0.8 秒淡入淡出、拼接；`-c:v libvpx -auto-alt-ref 0 -f ivf` 输出 IVF。
3. **IVF 转成游戏的 CAMV 容器**：41 字节的头 + 原样的 VP8 帧 + 每帧 9 字节的索引表（偏移、长度、是否关键帧）。这个格式是把原版的开场动画转成 IVF 再转回去、逐字节一致之后确定的。输出 `movies/rtz_384_intro.ca_vp8`。
4. **接进游戏**：生成器改 `videos` 表里 `ep_faction_intro_all` 那一行，指向我们的片子；配音指向一个不存在的事件（= 静音），字幕关掉。
5. **开局加载图**：4 张（1920×1080 一份、2560×1440 一份），覆盖 `ui_campaign_begins_ep_1..4` 的图和文字；标题、正文是界面自己叠上去的。
6. **选年份界面的小圆标**：66×66，画一个"淝"字。

这些只在八王之乱里用到，190 不受影响。结果按输入的哈希缓存（改一句诗才重新编码）。实测：开场在游戏里正常播放，可以跳过。

### 分镜和背景怎么交给出图方

1. **先定分镜**，一幕一行：地点·人物（题目）、谁的立绘、几秒、这一幕想让人感到什么（淝水是溃败，长安是困守，最后一幕要有希望）。整段 80 秒上下，10 幕左右；开头交代大事件，中间一家一幕，后面几幕留给日后登场的人（桓玄、拓跋珪、刘勃勃、孙恩、刘裕），最后一幕收全局。
2. **每幕背景写一段提示词**：只画环境（城、河、营地、田野），不画人、不写字、不盖章、不加框；左边约 45% 要安静（天空、水面、雾），那里叠题目和诗；右边约 40% 是立绘站的位置，不放主体；时代细节（夯土城墙、木门、两汉魏晋的建筑）写清，明清元素列为禁止。规格 16:9，理想 2560×1440；出图方给的尺寸小一些也能用（流水线等比放大裁满）。通用规则见 [06](06_旗帜与美术资源生成.md)。
3. **一幕可以要几个版本**（白天 / 黄昏、换构图），玩家挑。384 里桓玄、刘勃勃、孙恩、刘裕和最后一幕都从暗色换成了明亮的版本——整段开场如果全是暮色阴云，看着压抑。
4. **出图方交的文件名**按 `bg_<序号>_<名字>[_版本].png`，数据里 `background:` 写哪个就用哪个；换图只改这一行。

### 诗怎么配

384 最后定下来的十首里，有四种来源——每一种都要在数据的 `source:` 里写清楚：

| 来源 | 例子 | 注意 |
|---|---|---|
| 史书原文 / 童谣 | 关中：“凤皇凤皇止阿房”（长安童谣，凤皇是慕容冲的小字） | 最好，但能用的很少；照原文，不改字 |
| 前人诗词借咏 | 淝水：李白“但用东山谢安石，为君谈笑静胡沙”；天下：辛弃疾《南乡子》“何处望神州？满眼风光北固楼……” | 写明“借咏”“借景题辞”，不能让人以为是 384 年的人说的 |
| 后来语 | 桓玄：“父为九州伯，儿为五湖长！”（《晋书》载，桓玄日后的话） | 注明“后来语”——384 年他才十五岁 |
| 新拟 | 邺城慕容垂、孙恩、刘裕（化用辛弃疾《永遇乐》）、刘勃勃“欲筑高城吞万国，先将白骨奠山河” | 注明“新拟”；化用了谁也写上 |

写诗时几条经验：

- **跟着人走，不跟着事件走**：一幕一个人，诗写这个人此刻的处境（慕容垂“白发重临邺下”）或他日后的命运（刘裕“谁识布衣寄奴”）。
- **两个人的一幕，一人一句、对起来**：“凤皇凤皇止阿房，龙骧何事负秦王？”——前句是慕容冲（童谣），后句是姚苌（新拟）：凤皇对龙骧，阿房和秦王押韵；“龙骧”是苻坚当年把自己起家的将军号授给姚苌，这层旧恩让“负秦王”有分量。找对仗时先翻这个人的官号、小字、外号、事迹。
- **押韵、对仗比平仄要紧**：玩家看的是一眼的气势，不是格律；但同一首里别重复用韵脚字。
- **结尾那一幕要有余韵、有希望**：玩家不喜欢“时来天地皆同力，运去英雄不自由”（太丧气）；最后换成了辛弃疾的“千古兴亡多少事？悠悠，不尽长江滚滚流”，配北固楼凭栏望江的画。
- **写几个备选给玩家挑**，玩家自己拟的句子优先用；定下来以后再按句读排行（一行不超过 12 字左右，长的按原词的句读拆行）。
- 画面上**只放题目和诗**，出处不上画面、只留在数据里（`show_sources: true` 可以放回去）。

## 四、派系"势"：攒点、花点

### 384 里发生了什么

玩家："能不能加一套主动技能，像 190 里那种攒点然后可以使用的？"原版就有这个模式：八王之乱里司马伦攒「诡计」，190 系列里吕布攒「气焰」。先做了秦、燕两家试点，玩家看过后铺到 12 家，再到开放的 8 家地方势力，一共 20 家。

每家一种点数、三个能力，至少一个是打仗用的：

| 势力 | 点数 | 怎么多攒 | 三个能力 |
|---|---|---|---|
| 秦 | 天王余威 | 据长安 +2，胜仗 +2 | 天王亲征 · 开仓赈民 · 征发关中 |
| 燕 | 复国之志 | 取城 +3，胜仗 +1 | 复国号召 · 鲜卑铁骑 · 安抚河北 |
| 秦·关东 | 孤城死守 | 据邺 +2，胜仗 +2 | 以松喂马 · 邺城死守 · 征发关东 |

（全部 20 家见数据文件。）点数的名字和能力都从这一家的处境和史事里取：苻丕守邺"以松喂马"，姚苌"坐观成败"。

### 做法

数据 `data/faction_powers_384.yaml`：

```yaml
powers:
  former_qin:
    resource: 天王余威
    desc: 淝水一败，诸族并叛，可苻坚二十年混一北方的威望还在……
    start: 6
    cap: 60
    gains:
      per_turn: 1
      hold: [{region: 3k_main_changan_capital, points: 2, name: 长安}]
      battle_won: 2
      # capture: 3   每占一城
    actions:
      - {key: qinzheng, name: 天王亲征, desc: …, cost: 12, turns: 6, effects: {morale: 6, melee: 10}}
```

脚本 `rtz_era_384_powers.lua`（findings 第 75 条）：

- **点数存在存档变量里**（每家一个键），有上限。
- **攒**：`FactionTurnStart` 加每回合的固定值，再看据有的城（`cm:query_region(key):owning_faction()`）；`CampaignBattleLoggedEvent` 胜方将领的派系加点；`GarrisonOccupiedEvent` 占城的将领的派系加点。
- **花**：每个能力就是一个派系效果包，`cm:modify_faction(key):apply_effect_bundle(包, 回合数)`；派系栏里会显示它的名字、剩余回合和效果。把"生效到第几回合"也存进存档变量，生效期间同一个能力不能再用。效果包由生成器按效果简写生成（和派系特色同一套简写）。
- **入口**：左上角派系栏里一个圆形「势」按钮 → 窗口：当前点数、怎么攒、每个能力的效果和状态（可以发动 / 点数不够 / 生效中还剩几回合）。窗口用各包共用的界面工具（384 自带一份，不依赖别的包）。
- **只给玩家自己的势力**；这一家没有配置就不出现按钮。AI 没有。
- 坑：模组加载器会按文件名调用同名函数 `rtz_era_384_powers()`，所以模块表另起名字（`rtz384_powers`），否则互相覆盖。
- 离线测试：每回合攒点、据城加点、胜仗只加一次、取城加点、到上限就停、发动扣点并挂包且不能重复、窗口能建出来且按钮能花点、没有配置的派系没有按钮、每个可选势力都有配置。

实测：秦 6 → 9 → 12 点，发动天王亲征后派系栏出现对应效果（6 回合）；选晋，窗口显示「中兴之望 6 / 60」。

## 五、试玩之后补的几处（2026-09-24）

### 「特有特征」和「人物」一栏

- 选派系界面「派系」一栏的「特有特征」（原版：兵种、建筑、差事的一排圆图标）是纯数据：
  - `frontend_faction_leader_unique_features` 一行一项：键、图标路径、`feature_type`（unit / building / ceo）、排序。
  - `frontend_faction_leaders_to_frontend_faction_leader_unique_features_junctions` 把首领和特征连起来。
  - 说明文字只有一个键：`frontend_faction_leader_unique_features_localised_description_<键>`。写法照原版：
    - 第一行 `[[b]]标题[[/b]]`；
    - 第二行 `[[col:scope_description]]类别[[/col]]`；
    - 效果一行一条，用 `[[col:green]]` / `[[col:red]]` 标好坏；
    - 最后一行 `[[i]][[col:flavour]]典故[[/col]][[/i]]`。
- 我们以前一行都没写，那一栏是空的。现在每家写：
  - 派系特色，图标用自家字旗；旗本来就对、没重画的，用原版旗帜文件夹里的图；
  - 只属于这一家的开局效果；
  - 藩镇猜忌（见第 13 节）；
  - 「势」：点数怎么攒，加上三个能力，写在同一个说明框里。
- **那一排只放得下四个圆图标**：进游戏看到晋的六个被截掉了两个。生成器检查每家不超过四项。
- 「人物」一栏的性格是 `frontend_character_ceos`（第 13 节）。

### 头像在界面上其实有好几套尺寸

我们的立绘被裁成几套给游戏用，每套用在不同地方，**每一处都要在游戏里看一眼**：

| 文件夹 | 用在哪 | 要注意 |
|---|---|---|
| `stills/bobbleheads` | 选派系地图的图钉 | 画在一个圆形底座上。原版的半身像填满圆环，只有头和冠露在上面；我们以前裁得太宽，肩膀从两边溢出。现在乘一个“钥匙孔”遮罩：圆环里面，加上方一个头宽 |
| `stills/mini`（30×30 / 48×48） | 战役地图放大后军队旗下的小头像；多半也是战斗里将领头顶那个 | 原版是缩小的整个头（连冠带领口，周围透明）。我们以前贴着脸裁成方块，冠被切平、四角伸出圆框。现在取整个头再裁成圆 |
| `stills/halfbody_large` | 选派系列表里的小圆头像 | 要打开版式里的“脸”那一层（第 9 节） |
| `stills/unitcards`（82×272） | 军队面板、战斗里的武将卡 | 卡框 82×202，立绘贴底、多出的一截伸出卡顶（头探出卡框是原版的样子），而且画在卡框**上面**。原版立绘左右、下边留 1~2 像素透明，卡框的细线才露得出来。我们以前铺到边，把卡框盖住，看着像溢到旁边的兵牌上。现在左右、下边留 2 像素透明 |

怎么对准：从原版包里把底座图和版式文件拆出来，按版式里的偏移把底座和头像叠在一张图上比对，再进游戏确认。

### 开场动画：字、画质、旁白

- **字**：
  - 标题用楷体。诗用开源（SIL OFL）的书法字体：先试行书，玩家最后选了草书。字体文件只用来画图，不打进游戏包。
  - 草书和行书的标点位置偏，问号还画得像别的笔画。所以诗按题画诗的样子，不加任何标点。
  - 题目和诗之间原来有一道红线，玩家不要，去掉了。颜色让玩家在几种里挑，最后是古铜色。
  - 都做成数据里的开关：`poem_font`、`poem_scale`、`poem_punctuation`、`poem_colour`、`rule_line`。
- **画质**：VP8 用 3M 码率，草书的细笔画和渐变都糊了。改成按质量编：`-crf 4`，上限 12M，`-deadline best`。截一帧和原图比，差别看不出来。片子从 24 MB 变成 87 MB。
- **旁白**：开局读条时念的是 291 年的八王旁白。只给原版的影片行挂一个不存在的配音挡不住。
  - 读条那段念的是首领行 `loading_screen_intro_video` 指向的那一行 videos 的配音。
  - 黑熊的做法：另建一行 videos，`video_name` 写 `0`，没有配音。
  - 我们：首领行的 `video` 指到自己的片子（自己的键，没有任何配音挂在上面），`loading_screen_intro_video` 指到那个空行。

### 底板剧本自带的界面机制要检查

- 八王之乱左上角有四个「阵营倾向」图标（心 / 思想 / 实力 / 财）。显示条件只看“当前战役是不是八王之乱”，读的却是只有原版王爷才有的点数。
- 我们的派系指上去，显示的是提示框模板本身（`DY_TEXT`、`Placeholder Description`），而且四个都显示同一个。
- 做法：自己带一份原版的派系栏版式，只把这两处显示条件改成永远不成立。原版版式文件是 CRLF 换行，查找时要兼容。
- 底板剧本里凡是“按剧本打开”、却依赖原版派系数据的界面，都要这样查一遍。

## 六、所以下次这样做

1. **选派系界面先分组**：主要势力一组、地方势力一组，写进壳表；底板剧本的旧派系在开局存档里设成不可选。
2. **想让哪家可选，就必须给它一个开局活着的壳**；换壳时用 `colours_from` 保住地图颜色。
3. **图钉位置写进开局存档的 `FACTION_INFOS`**（都城中心 ÷ 地图尺寸），外层内层都改；不要只改 override。
4. **开场动画**：先写分镜（每幕：地点·人物、题目、诗、几秒），交出图方画背景，再用流水线合成。画面上只放题目和诗，出处留在数据里。
5. **"势"每家三个能力**，从处境和史事里起名；点数的来源要贴着这一家的战略目标（守孤城的据城加点、扩张的取城加点）；先做两家试点给玩家看，再铺开。
6. 每一样都进游戏看一眼：两组列表、每家的头像和字、图钉、地图着色、开场播放、「势」窗口和效果。
7. **特有特征每家不超过四项**，说明文字照原版的格式写；「人物」一栏给君主写三个性格。
8. **头像每一套尺寸都进游戏看**：图钉（bobblehead）、放大后的军队标记（mini）、列表小圆头像（halfbody）、军队面板的武将卡（unitcards，卡框要露得出来）。
9. **开场动画按质量编码**，诗的字体、颜色、标点做成开关让玩家挑；读条旁白指到一个空的 videos 行。
10. **底板剧本里“按剧本打开”的界面**（八王之乱的阵营倾向这类）逐个检查，用不上的就在自带的版式里关掉。
