# 06 · 旗帜与美术资源生成

## 384 里发生了什么

借壳之后（见 [05](05_派系壳与借壳机制.md)），各家挂的还是 291 年那位王爷的旗：西燕打「中山王」、后秦打「長安王」、桓氏打「楚王」、北府打「東海王」。玩家看了截图问："各大势力的旗帜你确定都是对的吗？没有封王的可以用姓氏，比如桓，谢玄旗帜可以是北府。"我们先出了一张全家旗帜的方案图给玩家看，回复"非常好，去吧"，才批量画。

画旗时踩到的事：

- **有的壳和 190 共用旗帜文件夹**：八王之乱的"王"各有自己的文件夹（`ui/flags/ep_faction_prince_of_*`），但凉州、洛阳、铁弗、丁零、孙恩借的郡国派系，和 190 的同名派系共用 `ui/flags/3k_main_faction_*`。往里换图，190 也跟着变。办法（findings 第 58 条）：给它们另起文件夹 `ui/flags/rtz384_<势力>`，再覆盖 `factions` 表里那几行，只改 `flags_path` 一格（整行照抄，数据表的解码—编码是逐字节一致的）。
- **别的 Mod 也改了旗帜路径**：一开始只有这 5 家起了自己的文件夹，其余直接画进原版的文件夹。结果装着黑熊的核心包时，北府在选派系界面上还是「彭城王」——那个包把几位王爷的 `flags_path` 指到了它自己的 `…_fix` 文件夹。现在**每一家都用自己的文件夹、自己的 `flags_path`**，装什么别的 Mod 都一样。
- **散文件不起作用**：把旗帜图放到 `data/ui/flags/…` 下面当散文件，游戏不读（第 29 条）。必须打进 `.pack`。
- **换壳之后颜色**：后来有 8 家换到别的壳上（见 [11](11_选派系界面_开场动画_派系势.md)）。字旗的底色是按原来那个壳在地图上的颜色配的，所以地图颜色也照抄原来的壳（`colours_from`），旗和地图继续对得上。

## 一、旗帜的数据和文件

`data/flags_384.yaml`，一家一行：

```yaml
flags:
  former_qin:         {glyph: 秦,   field: "#0f5073", ink: "#e2b84a", trim: "#f1ede2"}   # 苻坚称“大秦天王”
  later_qin:          {glyph: 姚秦, field: "#8fa645", ink: "#2a2a10", trim: "#3a3a2a"}   # 和苻秦区分开
  jin_beifu:          {glyph: 北府, field: "#d7be4d", ink: "#2a1c10", trim: "#3a2f14"}   # 军号（玩家提的）
  jin_jingzhou_huan:  {glyph: 桓,   field: "#896294", ink: "#f3d98a", trim: "#2f2236"}   # 姓氏
  eastern_jin:        {keep: true}                                                          # 原版的旗本来就对
```

- **字怎么定**：称王称帝的用国号（秦、燕、代、西燕）；同名的国要区分（姚秦 vs 秦）；没有封王的用姓氏（桓、呂、翟、乞伏、爨）、军号（北府）、州名（并州、幽州、涼州）或自号（孙恩的「長生」，其党自号"长生人"）。用繁体，和原版的旗一致；一到两个字，两个字上下排。
- **颜色**：底色、字色、镶边色都从这一家现在的旗上取，也就是和地图上的势力色一致。
- **文件规格**（第 32、58 条）：一个派系的旗 = `flags_path` 指的文件夹里的
  - `ui_flag.dds`：512×512，DXT3，10 级 mip，平铺的旗面（旗面区域约 x 13..417、y 77..346）；
  - `<文件夹名>.png`（512）和 `mon_256.png` / `mon_64.png` / `mon_24.png`：飘动的样子；
  - `ui_flag_tassle.dds`：各家逐字节相同、全透明，自己新起的文件夹也要放一份。
- **工具**：`tools/make_flags_384.py` 画布、写字、出这几张图，放进 `source/ui/flags/rtz384_<势力>/`；生成器（`gen_era.py`）把对应派系的 `flags_path` 指过去。两边用同一个函数算文件夹名，不会对不上。画 20 面旗要一阵子，结果按输入的哈希缓存（`generated/flags_384.stamp`）。

开场背景的提示词（`art/intro/PROMPT_intro_384.md`）里写死的几条，下次照抄：

- 尺寸 2560×1440（16:9），PNG；画面里不能有任何文字、题款、印章。
- 构图给版式留位置：左侧约 45% 要安静（天空、水面、雾），那里叠标题和诗；右侧约 40% 是立绘站的位置，不放主体；主体放中间偏右的远景。
- 一组图像同一个系列：同一种画法、同一套色调（写意设色、赭石花青墨色为主）。
- 时代细节：夯土城墙、木构门楼、庑殿顶平缓出檐、双阙；牙旗、幡、具装骑兵；不要明清的飞檐、砖城、牌楼、火器。
- 每张给中文说明和一段可以直接用的英文提示词。

这些资源都只在八王之乱这个剧本里用到（加载图按"剧本 + 派系"挂，视频和圆标是八王之乱专用的那一行 / 那张图），190 不受影响。

## 三、所以下次这样做

1. **先列清单**：这个时代每家要显示什么字、什么颜色；出一张全家方案图给玩家确认，再批量画。
2. **一律用自己的旗帜文件夹**，覆盖 `factions` 表的 `flags_path`。不要往原版文件夹里画——别的剧本可能共用它，别的 Mod 可能改了路径。
3. **颜色跟地图走**：旗的颜色取自地图上的势力色；换壳时用 `colours_from` 保住原来的地图颜色。
4. **所有美术都打进包里**，不放散文件；生成物按输入哈希缓存，不进 Git。
5. **给出图方的背景提示词写清版式留白**：哪里叠字、哪里站人。

## 四、在游戏里怎么验证

- 选派系界面右侧的旗、外交界面的旗、战役地图上城池和军队的旗号：三处都看。
- 在"装着常见 Mod"和"只开自己的包"两种环境里各看一次（黑熊的核心包会改旗帜路径）。
- 190 开一局，确认同名郡国派系的旗没变。
- 选年份界面的小圆标、开局加载图的四张轮播。
