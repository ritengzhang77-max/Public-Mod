# 历史时代 Mod 制作方法论

[384 年·淝水之后](../384/README.md) 是这套流程做出来的第一个时代。这里记的不是 384 本身的内容，是**怎么把一段历史做成一个能打的 Total War: THREE KINGDOMS 剧本**这件事本身——从选材料、定人物，到画像、配数值、搭派系，再到脚本怎么写、怎么在真游戏里测出问题、怎么打包发布。目的是把这条路走顺一次之后，下一个时代（比如东晋末年、南北朝初年）能省掉重新摸索的时间。

每一节都是一次真实踩过的坑加上后来验证有效的做法，不是纸上谈兵的流程图。

## 新时代照着做的顺序

1. **选年份和快照月份**：比 2～3 个候选时点（派系是否均衡、名人是否在场、史料够不够、地图合不合），定一个月份。→ [01](01_深度研究与人物取材.md)
2. **建资料库**：派系、人物（生卒、亲属、职业、出处、置信度）、史料争议；对一份"玩家一定会找的人"清单查缺口。→ [01](01_深度研究与人物取材.md)
3. **定地盘**：先按郡给归属和把握程度，列出要拍板的问题；换好底板之后再做逐城覆盖。→ [01](01_深度研究与人物取材.md)
4. **选底板剧本、挑壳**：导出底板开局快照，做一次借壳实验；可选的势力挑开局活着的壳，日后入场的挑休眠的；查撞车。→ [05](05_派系壳与借壳机制.md)
5. **定人物名单**：谁开局生成、谁到岁数登场、本家没了投谁、谁摄政；每家上限；第一波做完全体、第二波保证人人有名有数。→ [02](02_人物取舍与分配.md)
6. **配数值和特色**：开局等级、职业（一辈子涨哪条属性）、天赋和外号；会称王称帝的人先天权威给够；跑五维总表扫一遍。再配派系特色（先进游戏读净收入再定军费减免）、招牌武将技（常驻被动为主、开局自带）、名器、姓名库、官名和等级、开局城况（没有屠城记载就不残破）。→ [04](04_数值设计与五维系统.md)、[12](12_派系特色_技能_名器与府署.md)
7. **立绘**：写通用提示词和补充要求，人物资料写成 yaml 生成提示词；出图后走裁切流水线；先出第一波。→ [03](03_立绘生成流程.md)
8. **旗帜和其他美术**：全家字旗方案给玩家确认后批量画，一律用自己的旗帜文件夹；加载图、时间线小圆标。→ [06](06_旗帜与美术资源生成.md)
9. **首回合脚本**：唤醒壳、生成人物、分地盘、清场、封官、成婚、带兵、附庸、开战、经济补偿；每步记日志；日后入场和登场。→ [07](07_脚本机制.md)
10. **自己的开局存档**：年份、谁能选、君主名字、胜利条件、政体；界面上写死的东西用版式文件覆盖。→ [10](10_开局存档与界面.md)
11. **选派系界面、开场动画、派系"势"**：两组势力、图钉位置、开场分镜和诗、每家三个攒点发动的能力。→ [11](11_选派系界面_开场动画_派系势.md)
12. **性格、关系、势力之间的机制**：君主和名人的史实性格（界面和游戏里一致）；人物关系按史事列对；这个时代最有特点的势力关系做成“一个数、两道线”的机制；叛军按地分家。→ [13](13_人物性格_人物关系与藩镇猜忌.md)
13. **测试**：离线测试和构建关卡每次都过；每天进真游戏开局、过回合，以日志和截图为准；不碰玩家的存档和设置。→ [08](08_测试基础设施.md)
14. **发布**：查清依赖（扫描 + 只勾自己的包实测）、被谁盖掉、包的大小，写兼容性说明，上传创意工坊。→ [09](09_发布与依赖管理.md)

第 5～12 步不是严格先后：实际上是一轮一轮地做，每一轮都进游戏验证、给玩家看，再改。

文中的文件路径（`data/…`、`research/…`、`tools/…`、`portraits/…`）指的是 384 源码目录 `TW3K/mods/era_384/` 下的文件；引擎通用的工具在 `TW3K/tools/`；"findings 第 N 条"指 `TW3K/docs/findings.md` 里编号的引擎实测结论。这些源码目前没有放进这个展示仓库。

## 这套方法论从哪来

不是先设计后实现的——是先做 384，踩了坑之后回头把"这个坑说明了什么通用道理"抽出来的。所以每一节展开后，开头都会是一段"384 里发生了什么"，然后才是"所以下次应该怎么做"。这样以后回来看，能对上当时的真实场景，不是一条脱离上下文的规则。
