# 疆域 · 384 年六月逐城归属

> [← 返回展示页](../README.md)　·　相关：[势力](factions.md) · [人物](characters.md) · [事件](events.md)

![384 年开局势力示意图](../images/territory_384.jpg)

快照时点是**公元 384 年六月下旬**（东晋太元九年 / 前秦建元二十年 / 后燕燕元元年）：淝水之战后半年，慕容垂已称燕王、正围苻丕于邺；慕容泓、慕容冲起于华阴，泓刚被杀；姚苌在渭北自立；苻坚困守长安；东晋收复了襄阳、上庸，正向淮北、河南推进；凉州梁熙、代北刘库仁和幽、平、青、并诸镇仍奉秦朔。

游戏地图是东汉末年的 84 个郡（含 9 座关隘）、两百多座城。归属**精确到城**：同一个郡里“城在甲手里、城外在乙手里”的，就按城分——邺是苻丕的孤城、城外的恭城是慕容垂的；长安归苻坚、城外的蓝田归慕容冲。新开局第 1 回合由脚本一次改完；夷洲、云南、永昌三郡不动，保持原版的小势力。

## 一郡分属两家的地方

| 郡 | 城 | 说明 |
|---|---|---|
| **东郡** | ★濮阳 → **燕**；东平 → **丁零** | 濮阳属燕；丁零翟氏此时还在慕容垂军中，给他们东平一座城落脚（折算黎阳、滑台一带），开局是燕的附庸 |
| **洛阳** | ★洛阳 → **秦·洛阳**；弘农 → **西燕** | 平原公苻晖镇洛阳，七月前后率七万众西归长安，其后入晋；弘农、华阴一带是慕容泓、慕容冲起兵之地，划给西燕 |
| **安定** | ★临泾 → **秦**；高奴 参䜌 三水 → **后秦** | 郡城临泾此时仍属秦；姚苌四月在北地称万年秦王，地图上没有北地郡，就近折算到安定北部的三座城（三水最接近北地 / 马牧） |
| **魏郡** | ★邺 → **秦·关东**；恭城 → **燕** | 邺是苻丕死守的孤城（郡治），城外的恭城是慕容垂的围城军——开局即交战 |
| **中山** | ★卢奴 → **秦·关东**；常山 → **燕** | 卢奴由秦将苻谟据守，慕容麟正在攻取；386 年成为后燕都城 |
| **勃海** | ★南皮 → **燕**；章武 → **秦·关东** | 南皮属燕；章武一带由秦将苻绍据守 |
| **安平** | ★信都 → **秦·关东**；巨鹿 → **燕** | 信都，秦将苻定据守，384 年底降燕；巨鹿一带已响应慕容垂 |
| **彭城** | ★彭城 鲁县 → **秦·关东**；农田 → **秦·青州** | 秦徐州刺史赵迁据守，八月谢玄收复 |
| **京兆** | ★长安 → **秦**；蓝田 → **西燕** | 长安。苻坚困守；慕容冲六月后进屯阿房，城外已非秦有——蓝田划给西燕，表示兵临城下 |
| **河东** | ★安邑 蒲州 → **秦**；平阳 → **西燕** | 安邑、蒲坂仍是秦地；平阳是慕容冲三月起兵之处，划给西燕 |

## 关于这张图

地图是**示意图**：游戏没有公开的地图坐标，每个郡的位置是按郡治在历史上大致的位置手工估的，海岸线和江河也是手描的。晕染的色块只表示“这一带的郡治归谁”，不是精确的边界。数据和脚本在 [`tools/`](../tools)：改 `territory_384.json`，再跑 `make_map.py` 就能重画。
